## Deferred

### 1. Background first-install reconnect (~3 days)

**What:** First reconnect runs in background, not blocking. Daemon starts up,
returns "ready" immediately, then works through the embedding queue.
User can store notes + search whatever's already embedded; sees a status
line "Indexed N / total".

**Why deferred:** Substantial daemon-state work (background task queue,
status reporting, race-condition handling between live writes + the
background pass).

**Where to start:**
- Add `BackgroundReconnectQueue` class in `packages/lore/src/engines/`
- Hook into daemon startup at the end of `bindRuntime`
- Status field on `/health` JSON: `{ indexer: { state, processed, total } }`
- Ensure live `store_node` calls during background indexing aren't lost

### 2. File-watcher → incremental embed pipeline (~3 days)

**What:** Lore watches the registered repo directories. On a file change:
re-parse just that file, re-embed its symbols, update graph. User never
runs reconnect; the graph stays current.

**Why deferred:** Cross-platform file watching is fiddly (chokidar / fs.watch
quirks); throttling on `git checkout` storms; per-language parser dispatch
needs a clean entry point.

**Where to start:**
- Add `FileWatcher` infrastructure in `packages/lore/src/engines/`
- New `ILorePlugin.onFileChange?(path, kind)` hook
- Developer plugin implements: re-parse one file, diff symbols, upsert
  changes only
- Throttle: batch events for 500ms, dedupe, fire one update per file

### 3. Native `onnxruntime-node` provider (~2 days)

**What:** New `EmbeddingProvider` that uses `onnxruntime-node` (native C++
binding) instead of Xenova-Wasm. ~5-10× faster on CPU on any platform.
Zero install cost beyond an npm dep.

**Why deferred:** Need to download model weights as binary blobs (Xenova
ships them via npm; onnxruntime-node needs an explicit download step on
first use), figure out the right model variants for each platform, plus
the CoreML execution provider for Apple Silicon for additional speedup.

**Where to start:**
- Add `onnxruntime-node` to root package.json
- New `packages/lore/src/providers/nativeOnnxEmbeddingProvider.ts`
- Re-use the model files Xenova already downloads (cached at
  `~/.cache/huggingface/hub/`)
- Add `lore embedder switch --to native-onnx --apply`
