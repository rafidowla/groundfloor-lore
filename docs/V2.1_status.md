## Recent architectural decisions — the "why" layer

### Why Option C over a conditional-gating Option B
Option B (wrap leaked logic in `if (pluginRegistry.isActive('developer'))`)
would have hidden the problem without fixing it. A family workspace
would still carry `CodeSymbol`/`CodeFile` tables on disk and core
would still mention gitnexus. Option C makes the boundary real.

### Why `ILorePlugin.api?: unknown` instead of typed generics
Generic `ILorePlugin<TApi>` propagates type noise everywhere
`PluginRegistry` is touched. `unknown` + caller-side cast
(`devPlugin.api as DeveloperApi`) keeps core fully agnostic at the
cost of two lines of cast in each caller. Worth it.

### Why disk-read via `gitnexus list` instead of asking users for repo path
Users who indexed their repos with GitNexus already have the
repo-path metadata; parsing `gitnexus list` is the least-friction
path. Fallback to graph-built symbol preview is silent when
gitnexus isn't installed or the path can't resolve.

### Why default reconnect threshold 0.65
Empirical: at 0.65 the 63-LoreNode dev graph gets ~65 semantic edges
(good signal). Dropping to 0.55 nearly doubles the count and brings
in cross-pillar matches but also weak links. Users can slide down
in Settings → Graph Connections → Advanced, or `--threshold` on
the CLI. The default keeps the graph visually legible.

### Why stratified top-K in reconnect
Without per-pillar caps, highly-similar sibling LoreNodes crowd out
file and symbol hits because content is textually close. Splitting
k hits into per-pillar buckets (lore + non-lore) forces cross-pillar
to the surface at any given threshold.

### Why the arch test has a baseline model instead of failing hard
Hard-failing on 33 existing violations would mean every commit on
this branch starts red. The baseline snapshots current legacy;
CI fails only on NEW violations. Keeps the signal useful without
blocking work on unrelated files.

### Why CLAUDE.md is the most important guardrail
The V2.1 conflation didn't happen because of a missing lint rule —
it happened because I had no rule telling me the plugin boundary
was sacred. Documenting the rule in the source-of-truth that shapes
AI behavior is what prevents recurrence. `test:arch` is the net
that catches it when the rule is forgotten.

## Non-goals still in effect (from `docs/V2_implementation_plan.md`)

1. DEF Cloud extraction — UI has a greyed radio; no auth/JWT/billing.
2. Pushing the Kùzu graph to cloud storage — strictly local.
3. In-engine binary parsing (video, OCR, audio) — delegated to the
   LLM's native capabilities; Lore never parses bytes.
4. Full Dataplane telemetry contract — only the boot health-ping ships.
