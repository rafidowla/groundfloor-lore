# Test Index — test/ → modules under test

> **What this is.** A map from each file in `test/` to the source area and
> the primary modules it exercises. Many tests are sprint-named
> (`sp22-…`, `sw14-…`, `spf5-…`) which tells you *when* a regression was
> added but not *what* it covers. This index closes that gap so a
> contributor touching, say, `engines/verbatimStore.ts` can find the tests
> that guard it.
>
> **How it's organized.** Tests are grouped by the `packages/lore/src/<area>`
> directory most of their imports point at. The "Primary modules under test"
> column lists the first-party modules each test imports (leaf filenames,
> truncated to the first few).
>
> **Naming legend.**
> - `spNN-…` / `spfN-…` — hardening-sprint regression tests (SP-01 … SP-25, plus F-series).
> - `swNN-…` — swarm-task regression tests (SW-01 … SW-32).
> - `phaseN-…`, letter-prefixed (`E2-`, `L1-`, `Z1-`, `S-…`) — earlier milestone suites.
> - `…-unit.ts` — fast, in-process unit tests (no daemon spawn).
> - `…-property.ts` — property-based / fuzz suites.
>
> **Maintenance.** Generated by scanning `test/*.ts` imports for SW-32 (F8).
> It is descriptive, not enforced — if you add or move a test, update the
> matching row (or regenerate). Do **not** rename test files to match this
> index; the sprint names are load-bearing history.

## npm test coverage notes (NW-2b)

### New test (NW-2b part a — E1b close-unit)

`nw2b-kuzu-result-close-unit.ts` — dedicated unit for `engines/kuzuResult.ts`.
Asserts the `queryRows` / `queryVoid` / `closeResult` close-every-result contract
using injected test doubles (no real Kùzu DB). Wired as `test:unit:nw2b-kuzu-result-close`,
chained into `npm test`. The `finally`-path test (case 3) will fail if
`closeResult()` is removed from the `queryRows` finally block, confirming it
actually guards the E1b SIGSEGV regression.

from the `npm test` chain (confirmed by transitive-closure trace per
audit finding `test-real-kuzu-tests-absent-from-npm-test` and

`npm test` — chaos suite runs in ~4.5 s (well under the 2-minute gate);
